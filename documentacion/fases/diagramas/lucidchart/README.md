# Diagramas editables de Sabueso

Los dieciséis modelos revisados están guardados en [Lucidchart](https://lucid.app/lucidchart/239ad02a-3960-471d-aa93-98dc2da833f4/edit). Cada página conserva figuras, textos y conectores independientes. El diagrama de casos de uso se mantiene sin cambios en `../casos_uso.html` y `../svg/casos_uso.svg`.

`Sabueso_Parte_1_Diagramas.drawio` es una copia editable importable mediante **Archivo → Importar → Importar documentos**. La importación crea un documento nuevo; para cambios habituales, abre el enlace de Lucidchart.

El informe incluye Gantt, contexto, estados, las dos secuencias, BPM propuesto, navegación de interfaces y los tres prototipos de pantalla. Las seis páginas complementarias contienen arquitectura tecnológica, Kanban, objetivos, alternativas, proceso actual y comunicación. Se conservan como apoyo y no amplían los entregables de la Parte 1.

Para actualizar una figura del informe, edita su página, exporta esa página a PNG con resolución suficiente y reemplaza la imagen correspondiente en Word manteniendo el número y el pie de figura. Conserva en el repositorio el HTML y el SVG asociados cuando cambie el modelo. Comprueba etiquetas, flechas, símbolos y fondos después de cada importación o exportación.
