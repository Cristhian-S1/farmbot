# DOCUMENTO INICIAL DE PROYECTO IV - 2026

## MÉTODO DE TRABAJO 
Desarrollo del proyecto de software relacionado a cada empresa, entrega y presentación de informes parciales, por parte de los alumnos de acuerdo a las siguientes actividades: 

1. Descripción de la empresa 
2. Planteamiento global del problema detectado (cuál es el problema) 
3. Planteamiento de la propuesta de solución del problema
4. Definir claramente en conjunto con el cliente los Requisitos funcionales y no funcionales de manera consensuada 
5. Diseño preliminar de la solución seleccionada
6. Selección de las Herramientas para la Implementación 
7. Lograr un documento de especificación de requisitos firmados por el proponente (cliente)
8. Planificación temporal del trabajo semestral (Carta Gantt)
9. Desarrollo del Software (de la Solución) 
    * Modelo de Negocio 
    * Modelo de Requisitos 
    * Modelo de Análisis 
    * IGU, Base De Datos, Prototipo Inicial, Validación por el Usuario 
    * Modelo de Diseño 
    * Implementación, Prototipo Final 
    * Pruebas 
    * Primera Versión 
    * Validación por parte del Usuario

Metodología Ágil, para la producción del proyecto 
UML para la documentación del proyecto
